📝 THAY ĐỔI CHI TIẾT:

1. BACKGROUND (Nền)
   - Body: #000000 (đen thuần)
   - Sections: #000000
   - Cards: #1a1a1a (đen nhạt)
   - Hover: #2d2d2d (xám đen)

2. TEXT (Chữ)
   - Heading: #f0f0f0 (trắng nhạt)
   - Body text: #f0f0f0
   - Secondary text: #a0a0a0 (xám sáng)
   - Gray text: #707070

3. BUTTONS
   - Primary: Nền trắng, chữ đen
   - Secondary: Border trắng, chữ trắng
   - Hover: Hiệu ứng trắng sáng hơn

4. CARDS & COMPONENTS
   - Background: #1a1a1a
   - Border: #333333
   - Shadow: rgba(255, 255, 255, 0.05)

5. FORMS
   - Input background: #2d2d2d
   - Input text: #f0f0f0
   - Border: #333333
   - Focus: Border trắng

🔧 NẾU MUỐN ĐIỀU CHỈNH:

Mở file: styles.css
Tìm dòng 1-15 (CSS Variables)

/* Muốn đen hơn nữa? */
--color-primary: #000000;  → Giữ nguyên (đã đen tối đa)

/* Muốn chữ trắng hơn? */
--color-white: #f0f0f0;    → #ffffff (trắng thuần)

/* Muốn cards sáng hơn? */
--color-secondary: #1a1a1a; → #2d2d2d (xám đen nhạt hơn)

/* Muốn border sáng hơn? */
--color-border: #333333;    → #444444 (xám sáng hơn)
