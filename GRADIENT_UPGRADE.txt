       #ffffff 100%     /* Trắng */

✅ GRADIENT PLATINUM (Cải tiến - 7 điểm màu):

✨ 2. HIỆU ỨNG SHIMMER - MƯỢT MÀ & LIÊN TỤC

✅ ANIMATION CẢI TIẾN:
   @keyframes shimmer {
       0%   { background-position: 0% 50%; }
       50%  { background-position: 100% 50%; }
       100% { background-position: 200% 50%; }
   }

🎯 CẢI TIẾN:
   - Duration: 3s → 4s (chậm hơn, mượt hơn)
   - Background-size: 200% → 300% (rộng hơn)
   - Animation: Liên tục không gián đoạn
   - Easing: ease-in-out (mượt mà)

✅ ÁP DỤNG CHO:
   ✓ Hero title - 300% size
   ✓ Section titles - 250% size
   ✓ Logo - 200% size
   ✓ All headings - 200% size
   ✓ Gradient text class
