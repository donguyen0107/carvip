Xem Blog Trang Chủ
Để trống để tự động tạo từ tiêu đề
Nhập URL ảnh từ internet hoặc đường dẫn local (VD: /sources/header.png)
Ảnh sẽ được tự động đẩy lên máy chủ ImgBB và chỉ lưu URL (tiết kiệm dụng lượng Redis)
Hướng dẫn sử dụng Editor
  • Sử dụng thanh công cụ phía trên để format text (in đậm, nghiêng, gạch chân, v.v.)
  • Chọn Header để tạo tiêu đề (H1 - H6)
  • Thay đổi kích thước chữ và màu sắc theo ý muốn
  • Chèn link, hình ảnh, video trực tiếp vào nội dung
  • Click "Chế độ HTML" để paste/edit code HTML trực tiếp
  • Editor tự động lưu nội dung dưới dạng HTML
Video sẽ upload thẳng lên Cloudinary. Redis chỉ lưu HTML và URL video.
